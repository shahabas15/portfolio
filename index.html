PROJECT CASE STUDY

Detecting AI and Human Generated Text

A machine-learning text classifier designed to identify patterns that help distinguish human-written text from AI-generated content.

Project overview

The project explores text authenticity classification using linguistic indicators, semantic document representations, and supervised machine learning. The goal is to provide a practical way to inspect text and estimate whether it is human-written or AI-generated.

Technology stack

PythonMachine LearningNLPDoc2VecSVM

Workflow

01DatasetCollect and balance labeled text samples.
02FeaturesExtract punctuation, sentence length, lexical richness, and semantic vectors.
03TrainingTrain and evaluate classifiers, focusing on SVM.
04EvaluationReview classification metrics and model performance.

Project highlights

  • Used a Kaggle dataset with more than 487,000 text samples as the source dataset.
  • Applied under-sampling to create a balanced working subset of 10,000 samples per class.
  • Explored linguistic features including punctuation usage, unique-word richness, sentence length, and text length.
  • Used Doc2Vec to create semantic document representations and evaluated SVM classification.
  • The project report records approximately 99% accuracy in model evaluation. Results depend on the dataset and evaluation setup.
